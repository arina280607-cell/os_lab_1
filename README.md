## Файлы

- [report.docx](report.docx) — проверенный отчёт с результатами и скриншотом.
- [notepad_profile.csv](notepad_profile.csv) — 1349 событий процесса Notepad.exe за интервал наблюдения.
- [notepad_save.pml](notepad_save.pml) — фрагмент обращений к тестовому файлу для открытия в Process Monitor.
- [проверка лр номер 1.txt](<проверка лр номер 1.txt>) — тестовый текстовый файл.

## Что исследовано

Во время записи событий в Блокноте изменён и сохранён текстовый файл. События отфильтрованы по имени процесса Notepad.exe и сгруппированы по назначению:

| Группа | Число событий |
|---|---:|
| Работа с реестром | 1132 |
| Файловые операции | 209 |
| Создание и завершение потоков | 4 |
| Загрузка библиотек | 4 |
| **Всего** | **1349** |

Сохранение файла подтверждается событием WriteFile с результатом SUCCESS, смещением 0 и длиной 57 байт. В записи PID Блокнота — 11516; при новом запуске он может измениться. Названия операций Process Monitor не устанавливают точную цепочку функций API и вызовов ядра.

## Просмотр результатов

1. Открыть `report.docx` в Word или совместимом редакторе.
2. В Process Monitor выбрать File → Open и открыть `notepad_save.pml`.
3. Найти событие WriteFile процесса Notepad.exe для тестового файла и открыть его свойства двойным щелчком.
4. CSV использовать для анализа полного сохранённого профиля. PML и CSV содержат разные выборки событий, поэтому их количество может различаться.

Программа для сборки не разрабатывалась: задание предусматривает исследование готового ПО. ЛР № 1 является сквозной; после следующих лабораторных отчёт необходимо дополнить сводной аналитикой по курсу.

Инструмент: [Microsoft Sysinternals Process Monitor](https://learn.microsoft.com/sysinternals/downloads/procmon).
